Welcome to Feather

Fast when open.
Almost gone when idle.

Feather keeps the browser shell lightweight, cold-unloads background tabs and gives you direct control over memory. Choose a starting profile and you can tune everything later.

RECOMMENDED

Low Memory

Keep one tab hot, unload hidden tabs quickly and enable RAM Guard. Best for gaming, streaming and lower-memory systems.

SMOOTHER

Balanced

Keep a few recent tabs warm for quicker switching while still preventing forgotten tabs from sitting in memory forever.

MIGRATION

Bring your browser data

Import Edge favorites, history and recoverable tab URLs. Passwords can be imported separately through Edge's supported CSV export.

Nothing here is permanent — every option can be changed later.
Feather uses Microsoft WebView2 for website compatibility. Its low-memory model comes from unloading inactive WebView controls instead of pretending every saved tab needs a live renderer.
