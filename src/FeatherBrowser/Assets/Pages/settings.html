Memory and tabs

Fine-tune how Feather handles background tabs and memory pressure.

Low memory mode Recommended
Fully unloads the oldest background tabs instead of keeping their renderer in memory. Frozen tabs already use no CPU.
Gaming Mode
Prioritises the active tab and reduces background activity.
Eco suspension
Suspends hidden warm tabs before they are completely unloaded.
Adaptive memory mode
Tightens the loaded-tab budget as Feather approaches your RAM Guard limit.
Cold-unload other workspaces
Tabs in inactive workspaces can be disposed immediately to minimise their RAM cost.
Automatic memory guard
Emergency-trims eligible background tabs once Feather and its Chromium processes cross the limit.
